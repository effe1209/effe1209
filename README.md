# Ciao, sono Francesco! 👋

Sono uno studente magistrale in **Artificial Intelligence** presso l'**Università di Pisa**. 
Unisco il rigore accademico del Machine Learning con un approccio estremamente pratico allo sviluppo software e all'ingegneria del software.
